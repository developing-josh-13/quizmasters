# Quizmasters

## Description
This is my online quiz project for Learning People as the end of my Front-End Development pathway. I am implementing my knowledge of HTML, CSS and JavaScript to make a website that is fully-functional and accessible, has an appealing style and is dynamic for the end user. Accessibility helps users with disabilities to understand, navigate and interact with the website in its entirety.

## Features

### Home Page
The home page contains a header with navigation links:
* Home button: return to the home page
* Quiz buttons: navigate to the start of a quiz of your choice
* Help button: navigate to a self-contained page with instructions on how to take the quiz, how it is structured and what happens at the end.


### Quiz Pages
The quiz pages will also contain a header with the same navigation links should you wish to change quiz, visit the How to Play page or return to Home.

There are a total of 5 quizzes, one on each of the following topics:
* Food and Drink
* Maths
* Music
* Sports
* Technology

Each quiz will have **5 questions** on its particular topic that I have pre-written and are shuffled on each new load of the browser. Every question will have a choice of 4 possible answers with only one of them correct. You may select only one answer for each question using radio buttons. When you have chosen your answer, there will be a button to click that takes you to the next question. At the end of the 5 questions, your score is calculated and displayed on the screen for you to see.
